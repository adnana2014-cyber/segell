# سجلّ

تطبيق ويب بسيط لتسجيل تقييم يومي من 1 إلى 10 (مثل جودة النوم)، مع خريطة سنوية ملونة لكل الأيام.

## المزايا
- صفحة يومية تعرض آخر ٧ أيام، ويبقى اليوم الحالي وأي يوم غير مسجّل مفتوحاً للتقييم.
- عدة خرائط بأسماء تختارها (النوم، الرياضة، المزاج…) ولكل منها تقييماتها المستقلة.
- خريطة سنوية أفقية أو عمودية، بألوان من الأحمر (1) إلى الأصفر (5) إلى الأخضر (10).
- تعديل عدة أيام دفعة واحدة (آخر عدد من الأيام، أو من تاريخ إلى تاريخ).
- يدعم الوضع الفاتح والداكن، ومصمم للجوال.

## التشغيل
افتح ملف `index.html` في المتصفح، أو فعّل GitHub Pages للمستودع.

عند فتحه خارج Claude تُحفظ التقييمات في متصفح الجهاز نفسه فقط.

## الخط
يستخدم التطبيق خط ثمانية إذا كان مثبتاً على الجهاز (من [font.thmanyah.com](https://font.thmanyah.com))، وإلا فخط IBM Plex Sans Arabic.
